# Marie Babysitting — Site Vitrine Multi-services

Site vitrine moderne présentant des prestations de services à la personne :
- 👶 Garde d'enfants (babysitting)
- 🐾 Garde et promenade d'animaux de compagnie
- 👵 Assistance et compagnie pour seniors
- 📋 Conditions Générales d'Utilisation (CGU) intégrées

## 🛠️ Technologies
- **HTML5** sémantique
- **CSS3** (mise en page responsive, design moderne et soigné)
- **JavaScript** vanilla (interactivité, animations et navigation)

## 🚀 Utilisation
Ouvrez simplement `index.html` dans votre navigateur Web préféré.
